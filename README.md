# רצף – יעדים ואימונים

אפליקציית web (PWA) לאייפון למעקב אחרי יעדים יומיים/שבועיים ואימוני חדר כושר.

- **יעדים** – כותרת, אייקון, צבע, תדירות (X פעמים ביום / ימים מסוימים / X פעמים בשבוע), פירוט, רצפים (streak) ויומן חודשי.
- **אימונים** – תוכנית לכל יום אימון, תרגילים עם סטים/חזרות/משקל, טיימר אימון וטיימר מנוחה, היסטוריה, גרפי התקדמות ושיאים.

כל הנתונים נשמרים מקומית בטלפון. גיבוי ושחזור דרך מסך ההגדרות.

## התקנה באייפון
1. פתח את הקישור ב-Safari
2. כפתור השיתוף ← "הוסף למסך הבית"
